# Learning Model

Neuro Map Studio treats map editing as learning, not just organization.

## Active Restructuring

Learners strengthen understanding by moving blocks, changing labels, and reorganizing relationships. The map should make it safe to experiment, recover, and revise.

## Retrieval Practice

Review pages and map prompts should encourage recall before rereading. Good next slices should make it easier to ask and answer small questions from memory.

## Dual Coding

The app combines plain language with spatial layout, color, shape, and relationship type. Visual encoding should clarify meaning without becoming decoration.

## Semantic Relationships

Relationship lines should explain why ideas connect: causes, funds, controls, benefits, costs, loops, exits, evidence, and contrast.

## ADHD-Friendly Design

Design defaults should reduce friction:

- low visual clutter
- compact help
- visible recovery controls
- clear labels
- short forms
- forgiving placement and drag behavior

## Dyslexia-Friendly Design

The UI should preserve:

- Comic Sans or similar dyslexia-friendly font stack
- generous spacing
- plain language
- read-aloud support
- sentence highlighting
- readable block text

## Tablet And S Pen Flow

S Pen and touch input are first-class learning workflows. Placement mode, drag handles, long-press menus, zoom controls, and selection toolbar actions should remain reachable without relying on desktop right-click.
