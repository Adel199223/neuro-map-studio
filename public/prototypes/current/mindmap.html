Quick map tips
Move blocks to test your understanding.
Use causes, controls, benefits, evidence, contrast, loop, and exit links to encode meaning.
Use color and shape only when they mean something.
Ask: Why does this block belong here?
Use focus and recenter when the map feels overwhelming.
Link types
causes = one idea produces another
funds = money moves into a player
controls = leverage shapes behavior
benefits = value flows upward
costs = burden lands on someone
loop = feedback cycle
exit = practical alternative
evidence = support / example
Shortcuts
Ctrl/Cmd+Z undo. Ctrl/Cmd+Shift+Z redo.
Shift/Ctrl/Cmd-click toggles blocks and relationship lines into the selection.
Desktop/trackpad box select: Shift-drag on empty canvas. Adds blocks to the current selection.
Drag a selected block handle to move selected blocks together.
Arrow keys nudge selected blocks. Shift+Arrow nudges farther.
Delete removes the selected blocks and relationship lines. Ctrl/Cmd+C/V/D copy, paste, and duplicate.
Ctrl/Cmd+A selects all map blocks and relationship lines when the canvas is active.
Use Zoom to selection in the selection toolbar to bring selected blocks or relationship lines into view.
Learning trick
Big block = main idea.
Small block = detail or example.
Thick link = important relationship.
Shape change = different kind of thinking: process, actor, cost, exit, or question.
