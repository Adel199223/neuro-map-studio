# Accessibility and Learning Review Skill

Review for:

- dyslexia-friendly typography and spacing;
- keyboard accessibility and focus states;
- reduced visual clutter;
- readable contrast without harsh glare;
- sentence/chunk highlighting where useful;
- small default panels with optional expansion;
- no controls covering core content unnecessarily;
- learning value: retrieval, elaboration, chunking, and visual encoding.

Run or request manual checks for:

- keyboard navigation;
- mobile/trackpad interaction;
- screen-reader labels for controls;
- print behavior;
- reduced-motion behavior;
- zoom levels from 50% to 200%.
